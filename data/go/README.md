# Bundled fixed GO/MGI inputs

These exact files regenerate the paper GO results and were byte-matched to official downloads. The original acquisition dates are unknown. The OBO header reports releases/2026-07-26; the GAF header reports format 2.2 and generation date 2026-05-21. Header identifiers must not be represented as recovered acquisition records.

Attribution: Gene Ontology Consortium; Mouse Genome Informatics, The Jackson Laboratory. GO data/products and MGI data/annotations declare CC BY 4.0 in their official policies:

- https://geneontology.org/docs/go-citation-policy/
- https://www.informatics.jax.org/mgihome/other/copyright.shtml
- Licence: https://creativecommons.org/licenses/by/4.0/

The resource bytes have not been modified. This directory includes ontology/annotations, not third-party website images. Preserve attribution and the SHA-256 checksums when archiving or redistributing. Current download links are mutable; a checksum mismatch must fail. These bytes are bundled directly in this repository; no separate resource archive or identifier is required to locate them. Check them with `python tools/verify_inputs.py --dataset go --data-root .` from the repository root.
